COME APPLICARLA
1) Esegui un backup della cartella locale evolve (o usa git).
2) Estrai la patch nella cartella radice del tuo repository evolve.
   Sovrascrivi solo i due file omonimi, rispettando le cartelle src/.
3) In PowerShell dalla cartella del repository:
     npm run build
   Solo se passa:
     git add src/components/life-profile-client.tsx src/app/globals.css
     git commit -m "Fix layout opzioni profilo Evolve"
     git push origin main
4) Quando Vercel mostra Ready, premi Ctrl+Shift+R sulla pagina /evolve/profilo.

Non devi eseguire SQL, cambiare Aruba, eliminare file o riavviare Supabase.
La patch e stata costruita confrontando gli SHA degli stessi due file
attualmente presenti nel repository GitHub main, per evitare patch fuori versione.
